# Prompt Template

Use this structure when creating the final output.

## 1. Selected Assets
- Logo: <path or placeholder>
- Product: <path(s) or placeholder>
- Asset status: real supplied assets / planned placeholders only

## 2. Poster Direction
One concise paragraph summarizing:
- occasion
- mood
- brand tone
- whether it is background-only or ready for compositing

## 3. Composition
State:
- chosen composition pattern
- title-safe area
- product-display area
- focal movement

## 4. Visual Elements
List:
- scene motifs
- seasonal cues
- foreground / midground / background elements

## 5. Color & Lighting
State:
- main palette
- accent palette
- lighting direction and softness
- atmosphere

## 6. Background Prompt
Write a complete generation-ready prompt.
This prompt should only generate:
- background
- atmosphere
- support plane / display surface
- seasonal elements
- spatial depth

Avoid generating:
- logo
- final product packaging
- text
unless the user explicitly wants a purely conceptual mockup.

### Background Prompt Formula
Create a 9:16 vertical premium commercial poster background for <occasion>.
Style: <tone>.
Scene: <main scenery and seasonal elements>.
Composition: <safe area + product area>.
Lighting: <light behavior>.
Color: <palette>.
Depth: <foreground/midground/background>.
Surface: <display surface description>.
No text, no logo, no product, no people.

## 7. Compositing Instructions
Specify:
- logo placement and size range
- product placement and size range
- shadow/reflection integration
- prohibited edits to fixed assets

## 8. Negative Constraints
Examples:
- no cheap promotional feel
- no excessive gold metallic stage
- no dense particles
- no blown-out bloom
- no fake package generation
- no AI-noise / cottony texture
